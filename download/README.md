# Bandizip

只有7-Zip能望其顶背的（解）压缩软件！

## 下载

**[点此前往Bandizip官网](https://www.bandisoft.com/bandizip/)**

*本人推荐**免费版**，但商业版的会更好用一些。*

## 与7-Zip的VS

**Round 1（性能）**
7-Zip的性能会更好一些，但支持的文件没有Bandizip多。

**Round 2（操作）**
7-Zip的操作比较“老”，Bandizip的图形页面（GUI）会更简单一些。

**一比一，大家看着下吧。**
